# 콤보 상자

`ComboBoxConfiguration`은 LVUI의 선언 값과 디자인 토큰이다. 기본 크기는 97×20 논리 px이며 왼쪽 여백 8, 오른쪽 여백 1, 방향 표시 크기 18, 모서리 반경 5이다. 메뉴와 선택값은 앱이 소유한다.

`iiGUI/ComboBoxModel.h`와 `iiGUI/NativeComboBoxView.h`가 입력 검증, 상호작용 상태, 글자·방향 표시 배치, 그리기, 접근성 표면과 수명을 소유한다. 방향 표시는 위·아래·양방향이며 primary와 borderless 톤을 지원한다. 텍스트는 남은 공간에서 오른쪽을 생략한다. `LVUI/NativeComboBox.h`는 설정과 버튼 메서드 계약을 주입하는 `ComboBoxBinding`을 제공하며 iiSDKCore 외 SDK를 직접 참조하지 않는다. 생성된 앱이 iiGUI 구현을 명시적으로 조합한다.

유효하지 않은 후보는 이전 값을 보존한다. 클릭·눌림·놓음·취소 콜백의 순서를 유지하며 콜백 중 재진입한 변경이 이전 변경에 덮이지 않는다. 퇴역 시 콜백과 메서드 참조를 해제하고 이후 변경을 거절한다. macOS arm64에서 모델, 생성 코드, 입력과 퇴역, 목록 선택기, 버튼 메서드, 격리된 설치 소비자를 창 없이 검사했다. OS 입력 장치와 다른 플랫폼의 실행 검증은 수행하지 않았다.
