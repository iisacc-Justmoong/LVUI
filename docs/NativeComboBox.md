# LVUI 독립 콤보 상자

`ComboBoxConfiguration`과 `ComboBox`는 LVUI가 소유하는 클릭 필드의 설정,
상태 색상, 글자와 방향 표시 배치를 정의한다. 기본 크기는 97×20 논리 px,
왼쪽 여백은 8, 오른쪽 여백은 1, 방향 표시 크기는 18, 모서리 반경은 5이다.
텍스트는 남은 공간에서 오른쪽을 생략한다. 방향 표시는 위·아래·양방향을 지원하며
primary와 borderless 톤, 활성 상태에 따른 색상을 제공한다. 메뉴, 목록 및 선택값은
앱이 별도로 소유하고 클릭 콜백을 통해 조합한다.

`NativeComboBox`는 범용 호스트 액션 표면, 글자 측정과 그리기 명령을 사용한다.
클릭·눌림·놓음·취소 콜백을 연결하고 접근성에는 버튼으로 노출한다. 유효하지
않은 설정, 다른 스레드의 변경과 폐기된 표면의 변경은 거절한다. 콜백 중 재진입한
새 설정을 이전 설정이 덮어쓰지 않도록 변경 순서를 확인한다.

기본 선언형 생성은 LVUI 소유 모델과 어댑터를 선택하며 텍스트, 방향, 톤, 크기,
색상, 활성 상태 및 콜백을 연결한다. 반응형 입력의 후보가 유효하지 않으면 기존
설정을 유지하고 바인딩 오류를 보고한다. 모델, 호스트 상호작용 및 생성 코드의
헤드리스 검사를 통과했다. 실제 OS 입력과 접근성 장치 검증은 수행하지 않았으며
명시적인 레거시 생성 경로는 아직 남아 있다.
