# LVUI 독립 스테퍼

`LVUI/Stepper.h`는 스테퍼의 방향 허용 정책, 크기와 버튼 시각 상태를 소유하는
표준 C++ 모델이다. 기본 표면은 18×18 논리 px, 모서리는 4이며 기본 방향은 위와
아래이다. 위쪽 절반은 +1, 아래쪽 절반은 -1을 요청한다. 단일 화살표는 허용된
방향만 발생시키고 비활성 상태는 요청을 무시한다. 수치 자체는 앱 모델이 소유한다.
색상과 톤 정책은 같은 LVUI 모듈의 독립 버튼 모델을 조합한다.

`NativeStepper`는 앱이 제공하는 범용 입력·그리기 표면에 모델을 연결한다.
포인터의 위·아래 위치, 방향키와 접근성 증감 요청은 같은 방향 정책을 따른다.
허용하지 않는 방향은 접근성 행동에서도 제외한다. 눌림, 놓음, 취소, 클릭 및
증감 콜백을 제공하며, 콜백 중 설정이 바뀌거나 위젯이 폐기되면 이전 요청이
새 상태에 영향을 주지 않는다. 비활성 상태와 비활성 조상은 입력을 받지 않는다.

기본 선언형 `Stepper`는 LVUI 어댑터를 생성하고 방향, 톤, 크기, 색상, 활성 상태와
콜백을 연결한다. 반응형 입력은 유효한 설정만 적용한다. 헤드리스 모델·호스트·
생성 코드 검사를 통과했다. 실제 OS 입력 및 스크린 리더 검증은 수행하지 않았으며,
Windows와 Linux의 호스트 접근성 구현은 아직 미완성이다. 명시적 LVRS 생성 경로도
전환이 끝날 때까지 남아 있다.
