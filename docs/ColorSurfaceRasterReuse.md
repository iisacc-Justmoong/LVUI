# 색상 표면의 부분 갱신

iiColorManager를 연결하는 선택적 애플리케이션 색상 어댑터는 색상 값과 마커의
변경이 항상 표면 픽셀 전체의 변경을 뜻하지 않는다는 점을 보존한다. 같은 표면
종류·크기와 픽셀 계산에 필요한 HSB 성분이 유지되면 래스터 계산을 재사용하고,
현재 색상·마커·리비전은 매번 최신 상태로 반환한다.

색상환·스펙트럼·색상 레일은 현재 HSB에 의존하지 않는다. 채도·명도 평면은 색상,
색상·채도 평면은 명도, 명도 레일은 색상과 채도에 의존한다. 입력 크기나 필요한
성분이 달라지면 새 픽셀을 계산한다. 잠재 색상과 편집 취소·승인의 의미를 유지하고
오래된 리비전은 반환하지 않는다. 래스터 캐시는 항목 수와 바이트 수를 제한하며
실패한 계산을 보관하지 않는다.

이 최적화는 표면 계산을 제공하는 `ColorSelectionSurface` 예제 어댑터의 책임이다.
임의의 사용자 `ColorSurfaceSource`에는 계산식이나 의존성을 가정하지 않는다.
공개 프레임 계약은 여전히 독립적인 RGBA 바이트를 반환하므로 캐시 적중 시에도
호출자 소유 버퍼를 복사한다. 후속 iiGUI는 픽셀이 같으면 불변 GPU 이미지 객체를
유지할 수 있다.

헤드리스 검사는 각 표면의 의존성과 캐시 적중·축출·실패 복구를 확인하며, 여러
색상과 잠재 색상 전환에서 캐시 결과를 iiColorManager의 전체 래스터와 비교한다.
이 검사는 iPadOS의 실제 입력 지연이나 GPU 실행을 대신하지 않는다.
