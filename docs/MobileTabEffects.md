# 모바일 탭 재질·배지·선택 모션

`MobileTabBar`는 iOS 스타일에서 LVUI의 반투명 Material 표면을 사용하고,
`MobileNavigationBar`와 Android 스타일은 Figma의 불투명 표면을 사용한다. 재질은
호스트가 제공하는 이전 레이어를 합성하며 앱이 별도로 지정한 배경 이미지에 의존하지
않는다. 탭별 숫자·문자 배지와 점 배지는 항목에 속하고 탭의 접근성 설명에도
반영한다. 빈 배지와 꺼진 점은 아무것도 그리지 않는다.

선택 표시는 개별 탭이 아니라 공유 표면이다. 선택이 바뀐 경우에만 양 끝이 늘어났다가
목표로 수렴한다. 호스트 프레임 시계는 이 전환 동안에만 요청하며, 모션을 끄거나
시스템의 움직임 줄이기가 켜지면 즉시 목표에 도달한다. 뷰가 사라지면 프레임 요청도
퇴역한다. 비활성화 또는 숨김도 전환을 끝낸다. 탭 항목이나 너비가 바뀌면 유효한
새 위치로 즉시 정렬한다. 숫자 및 점 배지 크기는 기존 모바일 컴포넌트의 계약을
따르며 호스트의 실제 유리 합성과 플랫폼 접근성 동작은 별도 검증이 필요하다.

선택 상태·배치·프레임 모션과 재질·배지의 위젯 조합은 iiGUI가 소유한다. LVUI는 디자인 치수와 바인딩을 제공하며 Core 외 SDK를 직접 참조하지 않는다.
