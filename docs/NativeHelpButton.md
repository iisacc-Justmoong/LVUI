# LVUI 독립 도움말 버튼

도움말 버튼은 LVUI 버튼의 교체 가능한 시각 정책을 조합한다. 기본 표시 문자는
`?`, 접근성 이름은 `Help`, 기본 크기는 21×21 논리 px이고 좌우 여백은 4이다.
반경 100은 실제 크기에서 원형으로 제한한다. 글자는 12 px, 두께 600, 줄 높이 12이며
세로 중심에서 0.5 px 아래에 배치한다. 기본 배경은 하위 표면 색상, 글자는 설명
색상을 사용한다.

기본 선언형 `HelpButton`은 이 설정과 범용 액션 표면을 사용한다. 텍스트, 활성
상태, 톤, 크기, 여백, 모서리, 글꼴 크기와 줄 높이, 텍스트 세로 위치, 접근성
이름 및 색상을 반응형으로 지정할 수 있다. `backgroundColor`, `hoverColor`,
`pressedColor`는 기본 톤의 상태별 색상을 바꾼다. 잘못된 후보는 적용하지 않으며
정상 후보로 복구한다. 세그먼트 묶음 안에서는 다른 버튼과 같이 임시 톤을 받는다.
파괴적 톤은 컴파일 시 선택한 공통 빨강의 호버·누름 토큰도 사용한다.
`motionEnabled`는 상수 또는 반응형 값으로 지정하며 기본값은 `true`이다.
변경 중인 색상·포커스 전환의 처리와 전역 축소 모션의 우선순위는 [공통 버튼 계약](NativeButton.md)을 따른다.
`onPressed`, `onReleased`, `onCanceled`, `onClick`도 동일한 공통 버튼 입력
계약으로 전달하며 `method`와 `methods`도 같은 버튼 메서드 계약을 사용한다.
`enterKeyActivation`은 기본적으로 꺼져 있으며 상수나 반응형 값으로 켤 수 있다.

모델, 생성 코드, 범용 호스트 상호작용과 수명을 창 없이 검사했다. 실제 플랫폼의
시각·접근성 검증은 아직 남아 있다.
