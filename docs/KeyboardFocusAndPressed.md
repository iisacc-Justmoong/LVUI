# 키보드 포커스와 유지되는 누름 상태

LVUI 컴포넌트는 포커스 시각 상태를 키보드로 탐색하거나 조작할 때에만 표시한다. 포인터·터치·펜이나 자동 포커스로는 포커스 시각 상태를 표시하지 않는다. 텍스트 입력과 접근성에 필요한 논리 포커스는 유지한다.

기존 버튼의 `pointer_focus_visible` 설정은 소스 호환성을 위해 남아 있지만 값을 켜더라도 포인터 포커스 표시를 허용하지 않는다. 직접 상호작용 상태를 전달하는 호스트는 논리 포커스가 아니라 키보드 포커스 표시 여부를 시각 모델의 포커스 입력으로 전달한다.

메뉴 또는 팝오버를 연 컨트롤은 해당 팝업이 열려 있는 동안 누름 시각 상태를 유지하고, 닫히면 해제한다. 선택·호버·논리 포커스는 이 상태와 독립적이다. 이 동작은 개별 앱의 스타일 오버라이드가 아니라 iiGUI 공통 입력·표시 계약을 통해 제공한다.

Figma의 버튼, 드롭다운, 메뉴, 목록, 계층, 입력, 슬라이더 및 탭 컴포넌트에도 같은 동작 주석을 둔다.
