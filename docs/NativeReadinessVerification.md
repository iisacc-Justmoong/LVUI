# 네이티브 뷰 작성 준비 검증 기록

2026-10-27의 종료 기준은 LVUI·iiGUI로 Dreamscapes의 뷰를 Qt/QML 없이 새로 작성할 수
있는 실행 경로와 시스템 SDK 설치이다. 제품 소스의 자동 변환이나 원본 LVRS 전체 API의
동등성과 구분한다.

## 실행한 검증

| 범위 | 일반 구성 | ASan/UBSan 구성 |
|---|---:|---:|
| LVUI 전체 회귀 | 331 | 331 |
| iiGUI 관련 회귀 | 132 | 132 |
| LVRS 전체 회귀 | 904 | 904 |

LVUI 전체 회귀 후 자동 대화상자의 embedded build 거부 경로에서 미사용 factories 인자를
정리한 마지막 변경에는 영향 범위 5개 검사를 두 구성에서 추가 수행했다. 전체 회귀와 이
후속 검사의 실행 시점을 최종 JSON에 따로 기록한다. 초기 시간 제한 초과와 재실행 기록도
숨기지 않으며, 해당 두 항목은 최종 분리 검사로 확인한다.

LVRS에는 실제 창 예제 19개와 헤드리스 모델·위젯·AOT·패키지·경계 검사가 포함된다.
NativeCreationWorkbench는 C++ 작업 큐가 계산한 RGBA 프레임 24개를 같은 NativeView에
전달한다. 실제 GPU 픽셀의 프레임 간 차이와 투명도, 캔버스 팬·타임라인 탐색·재생,
결과 선택·입력 보존·창 크기 변경·수명 종료·문서 revision 0을 확인한다. 절차적 렌더링
검사이며 AI 추론이나 Dreamscapes 제품 실행의 완료를 뜻하지 않는다.

## 이번 실행에서 바로잡은 경계

- 글꼴 관측을 뷰 루트 한 곳에 두어 대량 행의 구독 한도 소진을 방지한다.
- ActionSurface의 사용자 입력과 기본 활성화를 함께 유지하고 캡처한 행이 형제보다 먼저 입력을 받는다.
- 중첩 세대 루트의 크기 갱신, 후보 소스의 스크롤 위치와 예산 초과 오류 코드를 보존한다.
- 모델의 정상 접근을 닫은 뒤 마지막 소멸 알림을 별도로 전달한다.
- 엄격한 C++ 소비자의 미사용 인자 경고를 생성기·헤더·예외 경로에서 처리한다.
- 갤러리는 C++ Observable을 통해 진행 표시를 갱신하고 닫힌 뒤 프레임 작업을 계속하지 않는다.

위젯 ID 조회·부동소수점·부모 배치·첫 표시 프레임의 캐시·독립 ABI 검사의 조건을 실제
계약에 맞추었다. 원본 실패 로그와 후속 검사를 보존하며 검증을 제거하거나 전체 실패를
성공으로 바꾸지 않는다.

## 설치와 독립 소비자의 완료 판정

시스템 SDK 목적지는 `/Users/ymy/.local/SDK/LVUI`, `iiGUI`, `LVRS`와 검증된 의존 패키지이다.
설치 완료는 로컬 `build/lvui-completion/native-view/verification-20261027.json`의 최종 기록으로
판정한다. 이 기록은 재배치 소비자의 실제 실행, 기존 파일 백업, 설치 파일·심볼릭 링크의
해시 대조와 설치본만 사용하는 소비자의 실제 실행을 모두 요구한다. 소비자에서는 개발용
SDK build 경로가 의존 패키지로 선택되지 않는지와 실행 파일·연결 공용 라이브러리의
Qt/QML 의존성 및 LVUI 소스 해석기 부재를 확인한다.

## 적용 범위와 남은 사항

현재 Mac에서의 작성·실행 준비 근거이다. 원본 대응표는 149개 선언 중 partial 93개,
pending 56개, complete 0개를 유지한다. 상속 API와 다른 OS·GPU의 전체 동등성을 달성한
것으로 표현하지 않는다. 외부 이미지 코덱 일부는 macOS 27용이므로 구형 macOS 배포 키트
검증이 별도로 필요하다. 제품 QML 81개는 읽기 전용 관측 자료이며 Dreamscapes 변환·재설치와
제품별 응답속도 측정은 이 SDK 검증 범위에 포함하지 않는다.

## 새 설치 소비자의 시간 한도

오류 검출 구성의 새 패키지 소비자 검사는 설치·archive 인덱싱·25개 AOT 팩토리의 컴파일과
실행을 포함한다. 기존 240초 한도에서 두 번 시간 초과가 발생하여 원본 기록을 보존했다.
빌드·설치 검사의 한도를 600초로 조정하고 일반 구성에서 해당 검사를 단독 실행했으며,
오류 검출 구성에서는 전체 회귀를 다시 수행했다. 단계별 명령·종료 코드·소요 시간은
`presentation-evidence/installed-consumer-steps.json`에 남긴다. UI 지연 허용치가 아니다.

## 글꼴 초기화의 분리 재검사

언어 분리 검사 첫 시도에서도 Conditional.syntax가 원래 15초 한도를 초과했다.
원본 로그를 보존한 뒤 소스·한도를 바꾸지 않은 최종 두 항목 검사를 수행했다.

오류 검출 구성의 글꼴 AOT 기본값 검사가 30초 한도로 종료된 기록도 보존한다.
같은 바이너리의 단독 CTest는 원래 한도를 유지한 채 0.19초 만에 통과했다.
정지 시점의 유효한 호출 스택을 확보하지 못했으므로 원인은 확정하지 않으며, 소스나
이 검사의 시간 한도는 변경하지 않았다. 계층 AOT 목록 초기화도 한 차례 시간 초과 후
재시도에서 통과한 기록을 보존한다. 라우팅 AOT 작업 흐름과 페이지 메타데이터 등에도
시작 제한을 초과한 기록이 있다. 원래 30초 제한의 추가 분리 검사에서도 글꼴 및 계층
초기화가 시간 초과되었다. 원본 로그에서 항목을 모두 추출해 동일 바이너리·인자를
90초 초기화 한도의 재시도 없는 진단 CTest로 확인한다. 기존 제한 통과로 표시하지 않는다.
바이너리 해시와 원래 제한·진단 제한, 누락 없는 대상 목록과
원본 로그 해시, 전체 재실행과 분리 검사 결과를 최종 JSON에 함께 기록한다.
분리 검사 첫 실행의 글꼴 시간 초과도 보존한다. 직접 진단에서는 동일 글꼴 검사가 약
37초 뒤 정상 종료했고 조건식 검사는 약 0.02초에 완료되었다. 유효한 정지 스택이 없어
원인은 미확정이며, 이를 성능 개선이나 지연 해결의 증거로 표시하지 않는다.

## 진행 표시 곡선의 검사 시계

전체 오류 검출 회귀에서 ProgressBar OutBack 곡선 검사가 한 번 실패한 뒤 재시도에서
통과했다. 검사는 변경 후의 실제 시계를 시작점으로 가정하고 있었으므로 Core 프레임
시계를 알려진 시각에 고정하도록 보정했다. 제품 코드는 변경하지 않았으며 비교 허용치는
0.02에서 1e-6으로 좁혔다. 보정 뒤 두 구성의 관련 13개 검사를 재시도 없이 따로 실행한다.
전체 회귀와 검사 시계 후속 확인의 시점을 최종 JSON에서 구분한다.

## 공개 API와 에이전트 접점

LVUI는 `lvui-check <file.lvui>`, `lvui-check --keywords`와 `lvui-compile`을 설치한다.
에이전트는 소스 검사와 네이티브 C++ 생성을 앱 실행과 분리하여 호출할 수 있다.
iiGUI는 `WidgetMount::find`, `snapshot`, `dispatch_input`과 `Host::snapshot`을 공개한다.
호스트를 소유한 C++ 어댑터는 이 타입 지정 인터페이스를 통해 뷰를 탐색·관측·조작한다.
LVRS의 `ViewModelRegistry`는 키·뷰·설명자·읽기·갱신·관측 인터페이스를 제공하며,
`ItemModel`과 `NativeViewSource`는 앱별 모델·렌더러를 교체하는 공개 계약이다.
이 경로는 임의 앱에 접근하는 외부 원격 제어 서버를 자동으로 노출하지 않는다.
설치 소비자 self-test가 같은 공개 입력·조회 경로를 호출한다.
