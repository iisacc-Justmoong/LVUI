# AOT 컴파일과 네이티브 마운트

상태: 2026-10-20에 채택한 LVUI 아키텍처이다.
LVUI는 AOT로 컴파일되는 네이티브 언어이다.
이 문서의 컴파일러와 컴파일된 대상의 마운트 계약은 현재 LVUI 0.1 패키지에 구현되어 있지 않다.

<a id="selected-execution-model"></a>

## 채택한 실행 모델

LVUI 소스는 애플리케이션 실행 전에 대상 플랫폼의 네이티브 기계어로 컴파일한다.
그 결과인 네이티브 UI를 iiSDK 런타임에서 iiGUI의 그리기 대상으로 마운트한다.

```text
.lvui 소스 + 참조하는 C++ 선언
    -> AOT 컴파일과 네이티브 링크
    -> 네이티브 애플리케이션 또는 UI 라이브러리
    -> iiSDK 런타임이 컴파일된 UI를 iiGUI 그리기 대상으로 마운트
    -> 네이티브 갱신·레이아웃과 iiGUI 그리기
```

LVUI 인터프리터, 소스 표현식 평가기, 바이트코드 가상 머신, JIT 실행 경로는 없다.
JVM과 .NET/CLR도 언어의 실행 모델에 포함되지 않는다.
배포된 UI는 `.lvui` 소스나 컴파일러 도구 체인 없이 실행할 수 있다.

iiSDK 런타임은 실행을 호스팅하고 작업을 스케줄링하며 소유권·수명 관리에 참여하는
네이티브 애플리케이션 기반이다. iiGUI는 네이티브 GUI·그리기 기능을 제공한다.
이러한 책임은 관리형 언어 가상 머신을 도입하지 않는다.

<a id="build-time-responsibilities"></a>

## 빌드 시 책임

AOT 도구 체인은 배포 전에 채택한 언어 규칙을 처리해야 한다.

- 선언·컴포넌트 구조·import·표현식을 파싱한다.
- 이름·타입·C++ 공개 멤버·constness·호출 호환성을 확인한다.
- 일반적인 멤버 접근·호출 표현식·인자 타입 규칙으로 컴포넌트 입력과 callable 시그니처를 검사한다.
- `let`/`var` 선언과 지원하는 어노테이션 조합을 검증한다.
- 네이티브 스코프 활성화, 백엔드 생성·파괴, 동작 호출, 바인딩 접근, 관찰 지원 코드를 생성한다.
- 관찰 어노테이션 없이 비정적 값의 의존성 추적과 변경 전파를 제공한다.
- 대상 플랫폼에 필요한 C++ 백엔드·iiSDK/iiGUI 계약과 네이티브 UI 코드를 링크한다.

소스 검증은 런타임 백엔드 인스턴스를 생성하지 않는다.
가져온 객체는 계속 소유 스코프 활성화 시점에 생성한다.

컴파일러는 [메서드 참조와 명시적 호출의 구분](MethodReferences.md)을 유지한다.
컴포넌트 인터페이스가 콜백 매개변수 타입을 제공하고, 컴파일된 구현이 이벤트 계기를 제공한다.
언어 프런트엔드에는 `PushButton`이나 첫 번째 인자를 클릭 이벤트로 만드는 특별 규칙이 필요하지 않다.

C++23을 생성한 뒤 네이티브 컴파일러를 사용하거나,
다른 AOT 백엔드에서 네이티브 코드를 생성하는 방식을 구현 선택으로 고려할 수 있다.
컴파일러 백엔드·중간 언어·드라이버 이름·생성 파일 형식은 여기서 정하지 않는다.
요구되는 결과는 실행 전에 생성한 네이티브 코드이다.

컴파일된 데이터 테이블이나 디스크립터가 네이티브 콜백에 동반될 수 있다.
그 존재가 LVUI 소스·바이트코드의 런타임 평가기를 허용한다는 뜻은 아니다.

<a id="mounting-responsibilities"></a>

## 마운트의 책임

마운트는 iiSDK 런타임에서 컴파일된 UI 인스턴스를 iiGUI 그리기 대상에 연결한다.
계약은 다음 책임을 다뤄야 한다. 이는 제안된 API 이름이 아닌 요구사항이다.

| 책임 | 필요한 동작 |
|---|---|
| 스코프 활성화 | 마운트된 뷰의 정체성을 설정하고 소유 import와 바인딩을 활성화한다. |
| 호스트 문맥 | 대상의 뷰포트·배율·소유 UI 실행 영역을 제공한다. |
| 입력과 동작 | 지원 입력을 컴파일된 네이티브 콜백과 기존 백엔드·쿼리 계약으로 전달한다. |
| 상태 갱신 | 관찰된 변경을 의존 네이티브 뷰 상태에 적용하고 필요한 레이아웃·그리기 작업을 요청한다. |
| 그리기 | 마운트된 UI의 결과 그리기 데이터를 iiGUI를 통해 제출한다. |
| 마운트 해제 | 접수를 닫고 연결을 분리하며 활성 사용을 종료한 뒤 소유 객체·그리기 자원을 해제한다. |

마운트 시 `.lvui` 소스를 파싱하거나 컴포넌트 선언을 해석하거나 버튼 클릭마다 백엔드를 생성하지 않는다.
[스코프 기반 import](TypeImports.md)와 [종료](InvocationLifecycle.md) 계약은
컴파일된 UI에도 계속 적용된다.

<a id="values-and-interactions-after-compilation"></a>

## 컴파일 이후의 값과 상호작용

AOT 컴파일은 실행 동작을 미리 확정한다.
뷰포트 크기·카운터 값·사용자 입력·쿼리 결과는 실행 중에도 달라질 수 있다.
필요한 속성 평가·레이아웃·상태 갱신은 컴파일된 네이티브 코드가 수행한다.

[기본 반응형 값 모델](ReactiveState.md)과 `@Static` 값 안정성은 컴파일되는 언어 의미이다.
`@Observable`은 선택적인 명시적 표기이며 활성화 요구사항이 아니다.
구현에는 네이티브 저장소·콜백·[Core 쿼리 계약](ViewModelQueries.md)을 사용할 수 있다.
런타임 어노테이션 해석은 필요하지 않다. 정확한 `@Static` 수명 소유자는
독립적인 [선언 설계 미정 사항](DeclarationAnnotations.md#open-questions)으로 남아 있다.

VM과 C++ 서비스는 기존 책임을 유지한다.
컴파일된 뷰의 마운트는 새 관리형 힙을 생성하거나 인스턴스 소유권을 변경하지 않는다.

<a id="dependency-boundaries"></a>

## 의존성 경계

애플리케이션과 생성된 UI 코드는 네이티브 런타임·그리기 계약을 사용한다.
Core는 LVUI 소스 구문과 애플리케이션 ViewModel로부터 독립성을 유지한다.
마운트 계약이 Core에 LVUI 컴파일러 import를 요구하거나 순환 의존성을 도입해서는 안 된다.

컴파일러 내부 구성과 공유 마운트 인터페이스를 소유할 패키지는 구현 결정으로 남아 있다.
런타임 그리기 대상은 이미 컴파일된 UI를 실행하기 위해 컴파일러 프런트엔드를 필요로 하지 않는다.

<a id="current-implementation-boundary"></a>

## 현재 구현 범위

기존 패키지는 [HTML 형태의 LVUI 0.1 계약](Language.md)을 위한 C++23 파서이다.
`CMakeLists.txt`는 `src/LVUI/Parser.cpp`를 `LVUI::LVUI`로 빌드하며 AOT 컴파일러 드라이버를 정의하지 않는다.

현재 iiGUI 연동은 이미 파싱한 `lvui::Document`를 받는다.

- `SDK/iiGUI/src/iiGUI/LVUI.h`는 `layout_view`를 선언한다.
- `SDK/iiGUI/src/iiGUI/Host.h`는 `Host::set_view`와 `Host::set_canvas`를 선언한다.
- `SDK/iiGUI/src/LVUI.cpp`는 문서의 레이아웃을 계산하고 `set_canvas`를 통해 프레임을 제출한다.

기존 파싱·레이아웃 경로는 AOT 컴파일러나 컴파일된 대상의 마운트 API를 입증하지 않는다.
실행 중 텍스트를 LVUI로 파싱하거나 평가해야 한다면,
네이티브 실행 파일에 소스 텍스트를 포함하는 것만으로 채택한 컴파일 모델을 충족하지 못한다.

<a id="future-implementation-validation"></a>

## 향후 구현 검증

- `.lvui` 뷰를 대상 플랫폼의 네이티브 UI 코드로 빌드한다.
- 애플리케이션 실행 중 소스를 읽거나 언어 컴파일러·인터프리터·관리형 VM을 호출하지 않고 해당 UI를 실행·마운트한다.
- 같은 소유 스코프 인스턴스를 유지하면서 컴파일된 네이티브 코드로 백엔드 동작·관찰·쿼리 전달을 수행한다.
- iiGUI를 통해 마운트된 대상의 크기를 바꾸고 갱신·그리기를 수행한다.
- 마운트를 해제하고 접수 종료·오래된 결과 거부·소유 백엔드와 그리기 자원의 사용 종료를 검증한다.

이는 향후 수용 기준이며, AOT 테스트 통과 보고가 아니다.

<a id="open-questions"></a>

## 미정 사항

- 네이티브 컴파일러 백엔드·빌드 드라이버 연동·대상 도구 체인.
- C++ 선언 탐색과 생성되는 네이티브 브리지.
- 애플리케이션·라이브러리 패키징, 진입점, ABI 호환성.
- 마운트 인터페이스 소유권·대상 정체성·활성화 실패 처리.
- 정확한 뷰포트·입력·갱신 계약과 그리기 제출 연동.
- 소스 진단·디버깅 정보·증분 컴파일.
