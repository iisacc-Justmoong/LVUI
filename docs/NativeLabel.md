# 네이티브 레이블

Society와 Dreamscapes의 레이블은 좁은 너비에서 여러 줄로 표시하거나 한 줄의 끝을
말줄임으로 생략한다. 기본 레이블은 사용 가능한 너비에서 줄을 바꾸고 내용 높이로
측정한다. `elideRight: true`는 한 줄 끝 말줄임을 선택하며, `alignment`는 왼쪽·가운데·
오른쪽 정렬을 지정한다. 텍스트·색상·말줄임·정렬이 모델에서 바뀌면 해당 레이블의
설정만 갱신하고 부모의 필요한 레이아웃을 무효화한다. 주기적인 재측정은 없다.
Python API `ii_lvui.compile_native`도 이 선언을 네이티브 C++로 생성한다.

정렬 상수는 `.left`, `.center`, `.right`이다. 반응형 정렬은 0, 1, 2를 사용한다.
현재 중간이나 앞쪽 말줄임, 서식 있는 텍스트와 별도의 단어·문자 단위 줄바꿈 선택은
지원하지 않는다. 실제 줄바꿈과 글꼴은 각 운영체제의 네이티브 글자 서비스를 따른다.
