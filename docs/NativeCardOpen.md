# 파일 카드의 선택과 열기

Dreamscapes의 저장소 파일 카드는 한 번 누르면 선택하고 두 번 누르면 연다.
`Card`의 `onClick`과 `onDoubleClicked`는 별개의 이벤트이며, 둘째 동작은 정상적인
두 번째 포인터 활성화가 완료된 경우에만 전달한다. 취소되거나 카드 밖에서 끝난
입력, 메뉴·액션 버튼, 키보드 활성화는 이중 누르기를 만들지 않는다. 운영체제가
탭 횟수를 제공하지 않으면 같은 장치의 인접한 포인터 입력을 시간과 거리로 판정한다.
선택 여부와 실제 파일 열기는 앱의 뷰모델이 소유하며 카드를 누른 것만으로 파일을
열지 않는다. 뷰가 퇴역했거나 비활성화되면 이후 콜백은 전달하지 않는다.
