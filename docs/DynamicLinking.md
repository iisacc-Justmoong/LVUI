# 동적 라이브러리 빌드

LVUI의 컴파일러 라이브러리와 네이티브 바인딩, 선택적 작업 런타임은 기본적으로
공유 라이브러리다. 기존 정적 연결은 `BUILD_SHARED_LIBS=OFF`로 선택한다.
공개 CMake 타깃은 유지되며 Windows에서는 DLL 심볼을 내보내고 iOS에서는
프레임워크로 설치한다. 애플리케이션은 실제 사용하는 런타임을 패키지에 포함한다.
호스트 컴파일러 도구와 Python 브리지는 재배치 시 인접 라이브러리를 찾는다.

테스트는 타깃 유형과 바이너리의 연결 정보를 확인하며 앱을 실행하지 않는다.
다른 운영체제 및 기기에서의 실제 동작은 별도로 검증해야 한다.

Emscripten 소비자 설정은 공유 사이드 모듈을 가져오기 전에 CMake의 공유 라이브러리 지원을 활성화한다. 앱의 메인 모듈 컴파일·링크 옵션은 빌더 또는 앱이 지정해야 한다.
