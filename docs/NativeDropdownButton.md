# LVUI 독립 드롭다운 버튼

`DropdownConfiguration`은 선언 값과 토큰을 제공하며 `iiGUI/DropdownButtonModel.h`는
액션 표면, 라벨 또는 아이콘과 아래 방향 표시의 상태 및 배치를 계산한다. 기본 높이는 22 논리 px, 라벨의 왼쪽
여백은 8, 오른쪽 여백은 2, 방향 표시 크기는 18, 모서리 반경은 8이다. 아이콘
배치는 기본 왼쪽 여백 4와 간격 -2를 사용한다. 메뉴와 선택값은 앱이 소유한다.
잘못된 설정은 유효한 기존 상태를 대체하지 않는다.
파괴적 톤은 공통 버튼의 상태 정책과 컴파일 시 선택한 빨강 호버·누름 토큰을 사용한다.

기본 `DropdownButton`, `LabelMenuButton`, `IconMenuButton`의 모델과 입력·그리기
호스트는 iiGUI가 소유한다. LVUI의 디자인 값·아이콘 공급자와 콜백 바인딩은
iiSDKCore 외 SDK를 직접 참조하지 않는다. C++ 소비자는 제거된
`lvui::DropdownButton` 대신 독립 `ii::gui::DropdownButtonModel` 또는 모델·호스트와
디코더를 주입하는 `DropdownBinding`을 사용한다. 포인터·키보드 입력과 클릭·눌림·놓음·취소 콜백,
버튼 접근성 이름, 반응형 옵션 및 폐기 후 접근 거부를 제공한다. 세그먼트 묶음의
임시 무테 스타일과 취소 콜백 중 재진입한 새 설정을 유지한다.

아이콘 모드에서 앱이 원본을 지정하지 않으면 LVUI가 작성한 폴더 형태 기본
도형을 표시한다. `iconName`은 [LVUI 내장 아이콘 또는 앱의 공급자](NativeIcons.md)를
조회하며 `icon`은 앱의 `shared_ptr<const ii::gui::RasterImage>`를 사용한다. 두
입력은 함께 지정할 수 없다. 알 수 없는 이름이나 유효하지 않은 SVG는 오류로
보고하고 이전 화면을 유지한다. 입력이 같고 공급자 리비전도 같으면 재조회하지
않는다. 명시적 `iconRevision` 또는 공급자 리비전이 바뀌면 다시 조회한다. 조회 중
재진입·퇴역된 오래된 요청은 적용하지 않으며 공급자가 계속 바뀌면 제한된 횟수 뒤
기존 상태를 유지한다. 퇴역 시 공급자와 콜백을 해제한다. 기본 도형의 실제 플랫폼
시각 일치와 전체 이름 기반 자산은 앞으로 검증·전환해야 한다.

`method`와 `methods`는 [공통 버튼 메서드 계약](NativeButton.md)을 따른다.
모델, 생성 코드, 범용 호스트 입력·수명 검사를 창 없이 수행했다. 실제 OS 입력과
접근성 장치 검증은 남아 있다.

macOS arm64에서 iiGUI 독립 모델·설치 소비자와 LVUI 디자인 값, 생성 및 호스트
검사를 통과했다. 실제 창·GPU와 다른 운영체제는 검사하지 않았다.

macOS arm64에서 Core 단독 바인딩과 생성 코드·아이콘 공급자·버튼 메서드 및
설치 헤더를 창 없이 검사했다. 다른 운영체제의 실제 렌더링은 검사하지 않았다.
