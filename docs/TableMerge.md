# LVUI 표 병합 데이터

`TableSnapshot::merges`는 0부터 시작하는 행·열 인덱스와 행·열 개수로 표현한
사각형 병합 목록이다. `TableIndex`는 범위가 표 안에 있고 두 병합이 겹치지 않는지
검증하며, `merge_at(row, column)`으로 기준 셀과 가려진 셀의 병합 범위를 찾는다.
빈 범위와 단일 셀 병합은 거절한다. 각 셀의 원래 값은 병합할 때 지우지 않으므로
나중에 분리하면 그대로 남는다.

`TableMergeEditor`는 앱이 교체할 수 있는 문서 편집 경계이고,
`prepare_table_merge()`는 리비전을 확인한 불변 후보를 만든다. 병합은 새 범위와
겹치는 기존 병합을 해제한 뒤 새 범위를 등록한다. 분리는 병합 안의 어느 셀을
지정해도 전체 병합을 해제한다. 이전 리비전, 잘못된 범위와 잘못된 동작은 거절하며
실질적인 변경이 없으면 새 리비전을 발행하지 않는다. 선택적
`TableMemoryMergeEditor`는 후보를 한 번에 게시한다. 외부 저장소는 같은 편집
인터페이스를 자체적으로 구현할 수 있다.

행·열의 크기 변경은 병합을 유지한다. 행·열 삽입·삭제나 순서 변경은 기존 위치의
병합을 해제한다. 동일한 키 순서를 유지한 데이터 교체는 병합을 보존한다. 이전
스냅샷은 계속 불변이다.

`TableController`는 가려진 셀의 선택을 병합의 기준 셀로 옮기고 선택 범위를 해당
병합 전체와 연쇄적으로 만나는 다른 병합까지 확장한다. 방향키는 현재 병합 내부를
건너뛴다. 병합이 기존 선택을 덮으면 다음 조회에서 선택을 기준 셀로 옮기고 뷰
리비전만 변경한다. 범위 계산은 행별 병합 구간 색인과 새로 추가된 영역을 사용한다.
클립보드 붙여넣기와 잘라내기는 병합 셀에 닿으면 모두 거절한다. 복사는 원래
각 셀의 데이터를 반환한다.

`TableViewportSource`는 기준 셀이 양축 화면 밖에 있어도 보이는 병합의 전체 위치와
크기를 반환하고 병합 전체를 기준으로 공개 위치를 계산한다. 독립 표 호스트는
기준 셀의 내용만 그리고 내부 격자선을 숨기며, 가려진 셀을 눌러도 기준 셀을
선택·편집한다. 화면에 보이는 병합 부분에서 기준 셀 편집을 시작할 수 있다.
앱은 `mergeEditor`를 공급하고 C++ 호스트의 `apply_merge()`를 호출할 수 있으며,
실제로 커밋된 변경은 `onMergeChanged`로 전달된다. 외부에서 편집기를 직접 호출한
경우에는 앱이 `modelRevision`을 갱신한다. 활성 셀 편집이나 크기 조절 중에는 병합을
거절하며, 재진입하거나 퇴역한 호스트의 오래된 결과는 다시 게시하지 않는다.

병합이 보이는 화면은 iiGUI 그리기 예산을 위해 최대 1,000개의 논리 셀을 허용한다.
이를 넘는 후보는 오류로 거절하고 기존 화면을 보존한다. 큰 병합의 텍스트 배치는
최대 8,192 논리 단위의 폭과 높이를 사용한다. 실제 플랫폼의 렌더링과 보조 기술
동작은 헤드리스 검사와 별개로 확인해야 한다.

`LVUI.OwnedTable.Merge`는 범위와 겹침 검증, 불변 후보, 병합·분리·무변경·오래된
요청, 숨겨진 값 보존, 구조 변경과 동시 편집, 연쇄 선택과 붙여넣기 거절을 검사한다.
`LVUI.OwnedTable.MergeHost`는 병합 그림과 내부 격자, 화면 밖 기준 셀의 편집,
호스트의 명령·재진입·퇴역을 실제 창 없이 검사한다. 생성 화면 검사는 외부 병합
후 반응형 리비전으로 표시를 갱신한다.
`LVUI.NativeInstalled`는 이동 설치된 공개 헤더와 컴파일러의 병합 편집·선언형
입력도 확인한다.
