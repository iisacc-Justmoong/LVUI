# LVUI 독립 라디오 버튼

`LVUI/RadioButton.h`는 디자인 값과 선언 계약을 제공하며 선택 상태·원형 기하와
모션은 `iiGUI/RadioButtonModel.h`가 소유한다. `iiGUI/RadioGroup.h`는 약한 참여자
인터페이스로 그룹을 관리한다. 입력·그리기 호스트도 iiGUI가 소유한다.
LVUI 바인딩은 iiGUI를 직접 참조하지 않으며 생성된 앱이 모델과 호스트를 조합한다. macOS arm64의 독립 설치 소비자와 기존 디자인·그룹·
호스트·생성 경로를 헤드리스로 검사했다.

```lvui
import vm EditorBackend
Window {
    VStack {
        RadioButton(text: "Original", group: "source", checked: vm.original,
                    onToggled: vm.chooseOriginal)
        RadioButton(text: "Edited", group: "source", checked: vm.edited,
                    onToggled: vm.chooseEdited)
    }
}
```

비어 있지 않은 같은 `group`에는 선택된 참여자가 최대 하나이다. 사용자 활성화는
현재 선택을 해제하지 않으며 새로운 항목을 선택했을 때만 해당 항목의
`onToggled(true)`를 호출한다. 그룹에서 밀려난 항목과 프로그램의 `checked` 변경에는
사용자 콜백을 보내지 않는다. 빈 그룹은 다른 버튼과 독립적이다. 하나의 생성된 뷰
활성화는 그룹 소유자를 가지며 중첩 스코프, 조건부 자식과 키별 반복 행이 이를 함께
사용한다. 별도 활성화는 기본적으로 별도 소유자를 가진다. C++ 앱은 생성된 스코프의
`radio_groups`에 공유 `lvui::RadioGroups`를 명시적으로 공급할 수도 있다.

후보 뷰는 그룹에 약하게 등록하지만 실제 선택에 참여하는 시점은 해당 세대와 모든
상위 후보가 공개된 이후이다. 생성이나 커밋이 실패한 후보는 기존 선택을 바꾸지 않는다.
복수 항목이 초기에 선택된 같은 그룹에서는 공개 순서상 마지막으로 참여한 항목이
선택된다. 퇴역한 항목은 제거된다. 그룹은 모든 관련 모델의 선택을 먼저 변경하고
호스트에 알리며, 알림 중 재진입이 발생하면 최종 상태를 다시 정리한다. 정리 횟수는
제한하며 선택·설정 호출에서 정리가 끝나지 않으면 `busy`를 반환한다. 공개 콜백은
반환 경로가 없으므로 그 시점의 정리 실패는 호출자에게 전파되지 않는다.
그룹 알림이 설정 갱신 중 다른 항목을 선택하더라도 텍스트와 접근성 이름을 포함한
최신 구성을 호스트에 전달한다. 그룹 소유자와 참여자는 UI 소유 스레드에서 사용한다.

`text`, `accessibilityName`, `checked`, `enabled`, `group`, `indicatorSize`,
`dotSize`, `labelGap`, `motionEnabled`, `motion`, `transitionDuration` 및 색상은 상수
또는 반응형 값이다. `state`는 `checked`, `available`은 `enabled`의 대체 입력이며
각 쌍을 동시에 지정하면 진단한다. 색상 입력은 `onColor`, `offColor`,
`onColorDisabled`, `offColorDisabled`, `dotColor`, `dotColorDisabled`, `textColor`,
`disabledTextColor`이다. 기본 표시기는 18 × 18, 점은 8 × 8, 텍스트 간격은 8,
본문은 13/13 Medium이다. 기본 점 전환은 원본 LVRS와 같은 360ms OutBack이며 앱이
모션 정책을 전달하거나 비활성화할 수 있다. 선택을 해제하면 점은 곧바로 숨기되
진행 중인 크기 값은 유지하므로 다시 선택하면 현재 크기에서 이어진다. 표시기 색상은 선택 또는 팔레트 변경 시 별도로
130ms OutCubic으로 RGBA 채널을 보간한다. 중간에 목표가 바뀌면 현재 표시된
색상에서 다시 시작한다. 모션 비활성화·축소 모션 또는 비활성 버튼에서는 즉시
정착한다. 프레임을 공급하지 못하는 호스트에서도 즉시 정착한다.
잘못된 후보는 이전 구성을 유지하고, 다른 반응형 입력의 변경은 사용자 선택을 되돌리지
않는다. 설정 변경은 UI 소유 스레드에서만 허용되고 종료된 뷰는 거부한다.

포인터·터치·Space/Enter 및 접근성 활성화를 범용 표면에서 받는다. 이름이 있는 같은
그룹에서 오른쪽·아래 화살표는 다음 항목을, 왼쪽·위 화살표는 이전 항목을 선택하고
포커스를 이동한다. 현재 표면의 실제 배치 순서(위에서 아래, 같은 줄은 왼쪽에서
오른쪽)를 사용하므로 반복 행의 재정렬을 따른다. 숨김·비활성·입력 차단 항목은
건너뛰고 끝에서는 반대쪽으로 순환한다. 변경된 항목에만 `onToggled(true)`를 보낸다.
빈 그룹, 다른 표면 도메인, 수정 키와 함께 누른 화살표는 다른 그룹으로 이동하지 않는다.
선택된 항목이 유일하면 선택을 유지한다.

그룹의 선택 경계는 특정 호스트에 의존하지 않는다. 다른 구현은 선택 참여자의
`RadioGroupMember`와 별도로 `RadioGroupNavigation`을 구현해 위치와 불투명한 표면
도메인을 제공할 수 있다. `navigation_members()`는 공개된 같은 이름의 참여자 중 이
선택적 포트를 제공하는 대상만 반환한다. 이용할 수 없는 대상은 위치를 반환하지 않으며,
유한하지 않은 좌표나 다른 도메인은 탐색에서 제외한다. 포커스 또는 선택 중 대상이
퇴역하거나 그룹을 바꾸면 오래된 선택을 수행하지 않는다. 플랫폼별 실제 화면·
스크린 리더 동작은 별도로 검증해야 한다.

`LVUI.OwnedRadioButton.Host`는 키보드 순환, 비활성·숨김·다른 그룹 건너뛰기,
반복 행 재정렬, 별도 표면, 잘못된 위치와 콜백 중 퇴역을 실제 창 없이 검사한다.
모델 검사는 기본 360ms 점 곡선과 선택 해제 시 즉시 숨김, 재선택, 색상 곡선과 점
모션의 서로 다른 종료 시각, 역방향 재목표, 팔레트·알파 변경 및 비활성·축소 모션을
확인한다. 생성 코드 검사도 기본 시간과 명시적 시간 지정이 각각 반영되는지 검증한다.

`tests/native_owned_toggle_consumer`는 별도 스테이징한 LVUI와 iiGUI만 찾아 스위치,
체크박스, 라디오의 생성 C++를 컴파일·링크한다. 검사는 창을 열지 않는다.

동일한 설정은 불필요하게 다시 게시하지 않는다. 그룹 알림 중 뷰가 폐기되어도
진행 중인 그룹 연산의 수명을 보존하고 퇴역 후 콜백과 그룹 참조를 해제한다.
