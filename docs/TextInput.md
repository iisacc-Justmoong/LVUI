# LVUI 텍스트 입력 상태

`LVUI/TextInput.h`의 `TextInput`은 UTF-8 문서, 선택의 시작점과 활성 커서,
운영체제의 조합 중 텍스트를 소유하는 C++ 값 모델이다. LVRS, Qt, QML과 위젯
호스트에 의존하지 않는다. 단일 입력은 NUL이 없는 유효한 UTF-8 최대 64 KiB이며,
공개 선택과 조합 범위는 운영체제 텍스트 서비스와 같은 UTF-16 단위로 표현한다.

생성자는 앱이 제공하는 `TextInputBoundaryFactory`를 받는다. 이 서비스는 불변
문자열 인덱스를 보유하고 UTF-16 위치의 UTF-8 바이트 변환과 확장 자소·단어
경계를 제공한다. 교체 가능한 이 경계는 텍스트 편집 상태를 소유하지 않는다.
인덱스 생성 또는 범위 검증이 실패하면 이전 텍스트와 선택은 변경되지 않는다.
서로게이트 쌍 중간의 선택과 범위, 잘못된 UTF-8, 크기 제한 초과를 거절한다.

일반 이동과 삭제는 주입된 확장 자소 경계를 따른다. 선택 범위는 운영체제의
조합 범위를 표현할 수 있도록 유니코드 스칼라 경계에서 설정할 수 있다. 조합을
시작하면 선택을 표시 문자열로 대체하고, 후속 조합은 현재 조합 범위를 대체한다.
확정은 시작 전 텍스트와 비교해 실제 수정 여부를 반환하며 `committed_text()`는 조합
중에도 확정 전 값을 제공한다. 취소는 시작 전 텍스트와
선택을 복원한다. 조합 중 삭제는 호출자가 먼저 확정하거나 취소해야 한다. 프로그램
텍스트 갱신은 조합을 끝내며 바뀌지 않은 텍스트는 커서를 유지한다.

`NativeTextBoundary`는 앱이 조합하는 범용 iiGUI Unicode 인덱스를 위 인터페이스에
연결한다. 이 어댑터는 편집이나 위젯을 소유하지 않으며 다른 Unicode 서비스로
교체할 수 있다. 한글, 결합 문자와 이모지 자소에 대한 메모리 검사가 포함된다.
`NativeTextLayout`은 원본을 줄 단위로 나누고 범용 글자 모양 서비스의 양방향
선택 구간·커서·위치 판정을 사용한다. 암호는 UTF-16 단위마다 마스킹하며 포인터가
원본의 서로게이트나 결합 자소를 쪼개지 않도록 보정한다. 최대 4096개 줄을
허용하며 긴 줄은 화면에 필요한 구간만 래스터화할 수 있다. 화면 줄바꿈은 아직
구현하지 않았고 명시적인 줄바꿈을 기준으로 배치한다.

기본 선언형 `InputField`는 이 모델과 [범용 호스트 어댑터](NativeInputField.md)를
사용한다. 실제 플랫폼 IME·클립보드·접근성 실행 검증은 추가로 필요하다. 현재
iiGUI의 Android·웹 글자 배치 서비스는 편집용 글자 배치를 제공하지 않는다.
