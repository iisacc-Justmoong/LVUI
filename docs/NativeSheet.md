# LVUI 독립 시트

`LVUI/Sheet.h`는 데스크톱과 모바일 시트의 설정·배치와 닫기 드래그 판정을
표준 C++ 값으로 소유한다. `automatic`은 창 폭이 아니라 호스트가 전달한 대상
플랫폼으로 결정한다. 데스크톱 기본 폭은 560, 선호 높이는 420이며 화면 양쪽의
24 여백 안에서 중앙에 배치한다. 모바일은 화면 전체 폭으로 하단에 정렬한다.
`fit`은 측정된 본문과 고정 영역 및 하단 안전 여백을 합하고, `medium`과 `large`는
각각 화면 높이의 57%, 90%를 사용한다. 모바일 높이는 상단 안전 여백과 최소 24를
남기도록 제한한다. 기본 반경은 데스크톱 16, 모바일 24이며 작은 프레임에 맞게
줄어든다.

호스트가 본문과 고정 영역의 자연 높이 및 플랫폼 여부를 전달하면 `layout()`이
프레임을 반환한다. 긴 스크롤 본문은 전체 자연 높이가 화면보다 커도 표시 가능한
프레임으로 제한한다. 명시적 presentation, detent, grabber 표시, 안전 여백과 반경을
지정할 수 있다. 유효하지 않은 설정은 기존 상태를 유지한다. `SheetDrag`는 모바일의
활성 드래그만 받고 위쪽 이동을 0으로 제한한다. 아래로 `min(120, 높이의 20%)` 이상
이동하면 닫기를 요청하며 짧은 이동은 원상 복귀한다. 포인터 캡처와 애니메이션은
호스트가 제공한다.

`LVUI/NativeSheet.h`는 범용 호스트의 팝업·스크롤·입력 경계에 이 모델을 연결한다.
본문 팩터리는 마운트 시 한 번 호출하며 닫고 다시 열어도 본문과 편집 상태를 유지한다.
재개방할 때는 스크롤 위치를 0으로 초기화한다. 제목·설명과 닫기 버튼은 본문 스크롤
밖에 있다. 시트 콘텐츠는 카드 경계에 잘린다. `scrollContent: false`는 스크롤을 끄고
본문을 뷰포트에 맞추어 자른다.
헤더 표시, 여백, 안전 영역과 기타 설정의 유효한 갱신은 본문을 다시 만들지 않는다.
모바일 grabber에서 받은 드래그의 이동량과 닫기 여부는 LVUI 모델이 결정한다. 짧은
드래그의 복귀는 현재 즉시 적용된다.

```lvui
import vm ExportBackend
Window {
    Sheet(id: "export", title: vm.title, presentation: .desktop,
          motionEnabled: false, onClosed: vm.closed) {
        InputField(id: "filename", text: vm.filename, onEdited: vm.edited)
    }
}
```

제목·설명·프레젠테이션·detent·크기·표시·닫기 정책과 색상은 선언형 상수 또는
관측 가능한 값으로 제공한다. 본문에는 여러 View를 넣을 수 있고 ID는 부모 마운트에서
유일해야 한다. `open: true`는 최상위 마운트 직후 한 번 열며, 반응형 `open`과 콘텐츠
팩터리 안의 초기 개방은 아직 지원하지 않는다. C++에서는 `root()`, `viewport()`,
`content_root()` 핸들과 콘텐츠 팩터리를 사용한다.

모션을 켜면 범용 호스트의 프레임 공급자가 필요하다. 공유 `motion` 객체, 드래그 복귀
애니메이션, 운영체제 안전 영역 자동 관찰과 실제 플랫폼 표시·입력·접근성 검증은
아직 남아 있다. 헤드리스 검사는 창이나 GPU를 실행하지 않는다. 레거시 타입이나
구현을 사용하지 않는다.
