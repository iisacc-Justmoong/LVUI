# LVUI 독립 세그먼트 묶음

`SegmentedControlConfiguration`과 `SegmentedControl`은 자식 동작이나 선택값을
소유하지 않는 시각 묶음의 배치, 배경, 테두리와 둥근 모서리를 정의한다.
기본 수평 여백은 4, 텍스트 행의 수직 여백은 3.5, 간격과 테두리 두께는 2,
모서리 반경은 12이다. 원통형은 사용 가능한 크기의 절반으로 모서리를 제한한다.

`NativeSegmentedControl`은 앱이 제공하는 범용 가로 배치와 그리기 표면을 사용한다.
교체 가능한 자식 스타일 포트에 무테 적용을 전달하며 유효하지 않은 후보는 기존
설정을 유지한다. 자식 포트가 새 설정을 거부하면 이미 적용한 자식도 복원하고,
갱신 중 재진입한 최신 설정을 오래된 호출이 덮어쓰지 않는다. 소유 스레드 이외의
접근과 폐기된 표면의 변경은 거절한다. 버튼의 임시 톤 포트는 원래 입력을 보존하고
비활성 버튼을 활성화하지 않는다. 폐기된 자식 포트는 명시적으로 정리하거나 등록
한도에 도달했을 때 정리한다.

기본 `LabelSegmentedControl`과 `IconSegmentedControl`은 이 어댑터로 생성한다.
직접 자식 버튼의 무테 설정은 반응형으로 바꿀 수 있고, 무테 적용 중에 변경한
버튼의 원래 톤은 적용 해제 시 복원된다. 중첩 컨테이너와 조건부·반복 활성화에도
같은 설정이 전달되며, 묶음을 중첩하면 가장 가까운 묶음이 해당 버튼의 톤을
결정한다. 분기나 반복 항목을 교체해도 새 버튼은 현재 설정을 받는다. 아이콘은
현재 앱이 공급한다. 모델, 호스트, 선언형 생성과 자식 수명 검사를 창 없이
수행했다. 레거시 생성 경로는 남아 있으며 실제 OS 창·입력·접근성 장치 실행은
확인하지 않았다.
