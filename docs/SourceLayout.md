# 소스 구조

`src/` 아래에서 컴파일러와 선언 언어, 스타일, 편집, 색상, 컬렉션, 오버레이, 탐색, 미디어, 레이아웃, 런타임과 일반 컨트롤의 책임을 나눈다. 구현이 있는 공개 헤더와 소스는 같은 디렉터리에 두며, `Keywords.def`와 스타일 토큰 생성 파일은 사용하는 구현 옆에 둔다.

빌드 중 생성 연결 헤더와 설치된 실제 헤더는 기존 `<LVUI/...>` 공개 경로를 유지한다. `LVUI.source_layout`은 책임별 파일 위치와 중복 디렉터리 재발을 검사한다. 이 변경은 LVUI의 Qt·LVRS 독립성이나 특정 운영체제의 실행 검증 범위를 확대하지 않는다.

설치 패키지는 `LVUI_AOT_FRAMEWORKS`에 지원하는 `iiGUI`를 노출한다. 소비자는 이 값으로 과거 LVRS 전용 생성 테스트의 실행 가능 여부를 판별할 수 있다.
