# TextEditor 줄바꿈 상태 알림

`TextEditor`의 선택적 `onWrappingFallbackChanged` 이벤트는 iiGUI가 현재 텍스트를
요청한 폭으로 자동 줄바꿈하지 못해 줄바꿈 없는 배치를 사용하는지 불리언으로
전달한다. 최초 상태를 한 번 알리고 실제 상태가 바뀔 때만 재통지한다. 뷰모델은
이 상태를 이용해 더 큰 문서 전용 뷰나 다른 명확한 대체 경로를 선택할 수 있다.

이 이벤트는 기존 텍스트·선택·복사 동작을 바꾸거나 레이아웃 및 입력의 크기
제한을 늘리지 않는다. 콜백을 생략한 기존 뷰는 계속 동작하며 iiGUI와 LVUI는
각자의 역할과 독립적인 모듈 경계를 유지한다.
