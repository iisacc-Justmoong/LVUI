# LVUI 독립화 작업 기록 — 2026-10-29

이 문서는 2026년 10월 29일 사용자가 작업 중단을 요청한 시점의 구현과 검증을
기록한다. **LVUI의 Qt·QML·LVRS로부터의 완전한 독립은 아직 완료되지 않았다.**
기본 생성 경로에는 LVUI 자체 구현을 다수 연결했지만, 명시적인 `FRAMEWORK LVRS`
생성 경로가 남아 있다. 이 기록은 구현 완료나 제품 출하를 뜻하지 않는다.

> 이후 같은 날 사용자는 LVUI를 `.lvui` 선언으로 iiGUI를 통해 운영체제별 위젯을
> 그리는 언어로 정의하고, LVRS의 기존 iiGUI 기반 네이티브 구현을 복제·리팩터링하는
> 이전 방식을 명확히 했다. 현재 우선순위는
> [네이티브 이전 우선순위](NativeMigrationRoadmap.md)를 따른다. 아래 구현·검증
> 기록은 중단 당시의 스냅샷이며 새 이전 작업이나 새 검증 결과를 뜻하지 않는다.

## 목표와 구현 경계

LVUI는 LVRS의 시각 언어, 스타일과 디자인 파라미터를 계승하는 독립 모듈이다.
컴포넌트의 모델, 상태, 동작, 배치와 그리기는 LVUI가 C++23으로 소유하고,
iiGUI는 범용 위젯 표면·입력·텍스트·팝업과 플랫폼 호스트를 제공한다. 앱은
iiSDKCore의 관찰 및 실행 경계와 필요한 데이터 공급자·편집기 인터페이스를
조합한다. 색상 값에는 iiColorManager를 사용하며, 색상 표면 어댑터는 선택적으로
빌드한다. 기본 빌드가 레거시 LVRS 체크아웃이나 Figma 접속을 요구하지 않도록
예약어·스타일 스냅샷과 필요한 아이콘 자산을 LVUI에 보유한다.

`LVUI::LVUI`는 파서와 네이티브 코드 생성기를, `LVUI::Native`는 생성 코드와
호스트 연결을 제공한다. `LVUI::Runtime`과 `LVUI::Color`는 선택적 구성 요소다.
앱이 사용하는 API와 교체 가능한 인터페이스는 LVUI 소스의 모델·어댑터에 있다.
개별 계약과 남은 범위는 [독립 구현 현황](LVUIIndependence.md)을 기준으로 확인한다.

## 지금까지 작성한 주요 기능

- **기본 컨트롤과 화면**: 진행 표시기, 버튼·도움말·드롭다운, 구분선, 메뉴와
  항목·직접 중첩 하위 메뉴, 팝오버, 모달, 경고창, 시트, 스위치·체크·라디오,
  슬라이더, 입력 필드, 스테퍼, 콤보 상자, 탭, 세그먼트, 툴팁, 이미지와 아바타,
  재질 표면, 링크·페이지 라우터, 앱 카드·헤더 및 이벤트 표면의 기본 경로를
  LVUI 모델과 어댑터로 작성했다. 각 기능의 미구현 입력과 플랫폼 제한은 각각의
  문서에 남겨 두었다.
- **색상**: 편집·확정·취소와 외부 변경에 따른 세션 만료를 다루는 색상 선택 모델,
  교체 가능한 색상 계산 경계, 표면·채널·값 필드·액션을 조합한 피커와 선택적
  iiColorManager 어댑터를 작성했다. [색상 피커](NativeColorPicker.md),
  [색상 선택 모델](ColorSelection.md).
- **목록과 계층**: 데이터 읽기·편집 인터페이스와 선택 상태를 분리하고, 고정 높이
  가상 행, 키 기반 상태 유지, 도구 모음·푸터, 계층 확장·선택과 드래그 이동을
  구현했다. 기본 목록·계층 패널은 자체 컴포넌트를 조합한다.
  [일반 목록](NativeOwnedListView.md), [계층 목록](NativeOwnedHierarchyList.md),
  [계층 패널](NativeHierarchyPanel.md).
- **목록 항목**: 기본·설명·탐색·토글·체크·액션·액션 그룹·스테퍼·선택·인라인
  편집 유형을 직접 작성하고 C++ API 및 기본 선언형 생성에 연결했다. 수량은
  경계·증분 모델이 관리하고, 선택기는 비활성 항목·메뉴와 긴 목록 스크롤을
  처리한다. 인라인 입력은 한글 등 조합 입력, 반응형 값 반영, 제출과 행 제거 시
  수명을 처리한다. 상세 복합·리소스·미디어·작업·폼 유형과 사용자 지정 자식은
  남아 있다. [목록 항목](NativeOwnedListItem.md),
  [수량](ListItemQuantity.md), [선택기](NativeOwnedListItemSelector.md).
- **표**: 교체 가능한 데이터 소스와 원자적 편집 경계, 선택·탐색, 양방향 가상
  표시, 셀 편집·검증, 범위 클립보드, 행 정렬과 구조 변경·크기 조절을 작성했다.
  머리글, 셀과 행도 LVUI 소유 모델과 호스트로 제공한다. 병합 셀과 일부 구조
  편집 UI 등은 남아 있다. [표](NativeOwnedTable.md),
  [머리글](NativeOwnedTableHeader.md), [셀](NativeOwnedTableCellItem.md),
  [행](NativeOwnedTableRow.md).
- **코드 편집기와 카드**: 코드 문서의 공유 불변 조각, 커서·선택, 입력 조합과
  가상 줄 표시를 분리하고 자체 편집 화면에 연결했다. 일반 카드는 여러 유형과
  크기·진행 상태·아이콘·이미지 입력을 자체 모델로 다룬다. 고급 편집 기능과
  카드의 사용자 컴포넌트·세부 표현은 아직 남아 있다.
  [코드 편집기](NativeCodeEditor.md), [카드](NativeOwnedCard.md).
- **메뉴 표시 범위**: 긴 메뉴의 내용이 화면에 맞춰 잘리고 스크롤되도록 바꿨다.
  포커스가 화면 밖 항목으로 이동하면 해당 항목을 표시 범위에 넣는다.
  [메뉴 계약](NativeMenu.md).

기본 선언형 컴파일러의 변경은 [Compiler.cpp](../src/Compiler/Compiler.cpp), 목록
복합 구현은 [NativeListItemComposite.h](../src/Collections/NativeListItemComposite.h),
메뉴는 [NativeMenu.h](../src/Overlays/NativeMenu.h)에 있다. 기능별 모델과 헤더는
책임별 `src/` 하위 디렉터리에 소스와 함께 배치되어 있다.

## 설치 패키지와 독립 소비자

액션 그룹까지의 이전 스냅샷은 별도 스테이징 패키지
`build/lvui-owned-package-20261029-list-actions`로 설치하고,
`build/lvui-independent-consumer-20261029-list-actions`에서 LVRS·Qt5·Qt6 검색을
비활성화한 소비자 프로젝트를 빌드하고 링크했다. 그 스냅샷의 생성 헤더와 연결된
동적 라이브러리에서 `LVRS`, `lvrs::`, Qt, QML 참조를 찾지 못했다. 소비자 실행
파일을 실행하거나 사용자 설치 위치에 배포한 것은 아니다.

최신 스테퍼·선택·인라인 편집을 포함한 패키지는
`build/lvui-owned-package-20261029-inline`에 별도 스테이징했다. 소비자 구성은
처음에 Vulkan 검색 경로가 없어 실패했고, 워크스페이스의 Vulkan 경로를 지정한 뒤
성공했다. 생성 코드가 만들어진 뒤 소비자 C++ 빌드를 진행하던 중 사용자의 중단
요청으로 멈췄다. 따라서 **최신 소비자의 컴파일·링크 성공과 최종 바이너리의
의존성 검사는 확인되지 않았다.** [구성 기록](../build/lvui-owned-package-20261029-inline/consumer-configure-retry.log),
[중단된 빌드 기록](../build/lvui-owned-package-20261029-inline/consumer-build.log).

## 남아 있는 의존성과 작업

1. `FRAMEWORK LVRS` / `--framework LVRS`는 여전히 `LVRS/Widgets.h`와 `lvrs::`
   타입을 생성한다. 선택적인 레거시 소스 조사 도구와 검증도 남아 있다. 이 경로를
   독립 구현으로 대체하고 제거해야 비로소 요청한 모듈 분리를 주장할 수 있다.
2. 상세 복합 목록 항목과 카드 슬롯·시각 세부 사항, 표 병합, 계층의 추가 편집 UI,
   코드 편집기의 고급 기능, 동적 메뉴 자식 등은 완성되지 않았다. 자세한 누락
   항목은 [독립 구현 현황](LVUIIndependence.md)과 기능별 문서를 따른다.
3. 현재 소스에 대한 전체 회귀, 최신 독립 소비자의 링크와 의존성 확인, 운영체제별
   실제 표시·입력·접근성 검증이 남아 있다. 앱 실행이나 기기 검증을 한 것으로
   간주하지 않는다.

이 기록 시점의 LVUI 작업 디렉터리에는 추적된 변경과 미추적 파일이 남아 있다.
`build/`의 스테이징 패키지와 검사 기록도 보존한다. 다른 작업의 데이터나 기존
빌드 증거를 삭제·초기화하지 않았으며, 사용자 요청에 따라 현재 목표 작업을 중단했다.
검증 중에는 스타일 예제와 색상 어댑터를 켜고 별도 iiGUI 호스트 경로를 지정했다.
중단하면서 `build/` 구성의 스타일 예제와 색상 어댑터를 다시 끄고 임시 iiGUI 경로를
제거했으며, 기존 런타임 설정은 유지했다. 위 검사 기록은 검증 당시의 구성에 해당한다.
