# 탐색 목록 항목의 값

Society와 Dreamscapes의 탐색 목록 항목은 이름과 설명 외에 오른쪽 값과 이동 아이콘을
선택적으로 보여준다. `value`는 앱이 제공한 UTF-8 문자열이고 `showValue`는 값 영역을,
`showTrailingIcon`은 별도의 이동 아이콘을 제어한다. 값이 설정되지 않으면 값 영역을
확보하지 않는다. 빈 문자열을 명시하면 공간은 유지한다. Figma Navigation 항목의 값
영역은 기본 72 논리 px이며 행이 좁으면 내용이 겹치지 않도록 양보한다.

값 변경은 해당 항목의 기존 위젯과 선택·포커스를 유지한다. 표시 중인 값은 접근성
설명에도 전달한다. 앱이 별도의 접근성 설명을 명시하면 그 값을 우선한다. 값과 아이콘
변경은 알림에 따른 부분 갱신이며 주기적인 목록 재구성은 하지 않는다.
