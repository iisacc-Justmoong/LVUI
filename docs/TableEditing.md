# 표 셀 편집 세션

`TableEditing`은 [표 스냅샷](OwnedTableModel.md)의 셀을 기준으로 원본 문자열,
작성 중인 문자열, 값 유형과 관찰한 리비전을 보관한다. 입력 중에는 소스를 수정하지
않으며 `set_draft()`는 UTF-8과 크기를 검증한다. 앱은 `TableEditor`를 주입해 정수,
날짜, 도메인 규칙 또는 영속 저장소의 검증을 별도로 적용할 수 있다. 기본 메모리
편집기는 문자열을 그대로 저장한다.

`commit()`은 한 셀의 변경과 시작 리비전을 편집기에 한 번 요청한다. 거절되거나
소스가 변경되면 원본을 덮어쓰지 않고 세션과 작성 중인 값을 유지한다. 성공하면
세션은 종료되고 다시 확정할 수 없다. `cancel()`은 편집 요청 없이 세션을 끝낸다.
확정 중에 같은 세션을 다시 확정하거나 수정·취소하려는 재진입은 거절한다.
세션은 생성한 스레드에서 사용하며 편집기는 리비전을 원자적으로 확인해야 한다.

`LVUI.OwnedTable.Editing`은 사용자 정의 타입 검증, 작성 중 원본 비변경, 거절 후
복구, 오래된 리비전, 취소, 재진입과 스레드 경계를 검사한다. 이 세션은
[독립 표 호스트](NativeOwnedTable.md)의 셀 입력에도 연결된다. 입력 필드는 하나의
활성 셀에만 만들며, 읽기 전용 셀은 편집하지 않는다. 헤드리스 호스트 검증은 실제
플랫폼 입력이나 보조 기술 검증을 대신하지 않는다.
