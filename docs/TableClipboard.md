# 표 범위 클립보드

`TableClipboard.h`는 플랫폼 클립보드나 위젯에 의존하지 않는 표 범위 직렬화와
붙여넣기 준비 기능이다. 탭으로 열을, 줄바꿈으로 행을 구분하며, 필드 안의 탭·줄바꿈과
따옴표는 큰따옴표로 감싸고 따옴표를 두 번 써서 보존한다. LF, CRLF, CR 줄바꿈을
읽으며 마지막 행 종료 문자는 새 빈 행으로 취급하지 않는다. 한 열의 마지막 빈 행도
직렬화와 복원 과정에서 유지한다. 각 필드는 NUL 없는 UTF-8이어야 한다.

`serialize_table_clipboard()`는 불변 스냅샷의 사각 범위를 문자열로 만든다.
`parse_table_clipboard()`는 모든 행의 열 수가 같은 입력만 허용한다.
`prepare_table_paste()`는 선택 영역과 입력을 검증하고 관찰한 리비전을 담은 하나의
`TableEdit`을 반환한다. 한 셀을 선택한 경우 입력의 크기만큼 확장하며, 한 셀을
복사한 경우 선택한 영역을 그 값으로 채운다. 그 밖에는 입력과 선택 크기가 같아야 한다.
대상을 잘라내거나 크기를 자동으로 늘리지 않는다. 비활성·읽기 전용 셀, 표 밖의 대상,
잘못된 UTF-8, 불균일한 행은 전체를 거절한다. 소스는 준비 중 변경되지 않으며 앱의
`TableEditor`가 리비전과 값의 유효성을 원자적으로 확인해 적용한다.

데이터는 최대 4,096셀과 1 MiB이며 한 필드는 최대 65,536바이트다. 한 셀로 여러
대상을 채울 때도 확장된 편집의 문자열 합계가 1 MiB를 넘지 않는다.

[독립 표 호스트](NativeOwnedTable.md)는 선택 범위의 복사·잘라내기·붙여넣기와
`onRangeValuesChanged`를 제공한다. 기본 연결은 iiGUI의 범용 클립보드 서비스를
사용하며 C++ 앱은 `NativeTableClipboard`의 읽기·쓰기 함수를 교체할 수 있다.
잘라내기는 쓰기에 성공한 뒤에만 셀을 지우고, 도중에 화면이나 소스가 바뀌면 새
데이터를 덮어쓰지 않는다. 활성 셀 입력 중에는 입력 필드가 그 자신의 클립보드를
처리한다. 표의 클립보드는 `clipboardEnabled`로 끌 수 있다.

`LVUI.OwnedTable.Clipboard`는 TSV 왕복, 빈 행, 유니코드, 잘못된 입력과 크기 제한,
범위 채우기, 읽기 전용 셀과 오래된 편집을 검사한다. `LVUI.OwnedTable.ClipboardHost`는
메모리 클립보드를 주입해 복사·잘라내기·붙여넣기, 실패·재진입·화면 제거를 헤드리스
트리에서 검사한다. 실제 운영체제의 단축키와 클립보드 동작은 별도 검증이 필요하다.
