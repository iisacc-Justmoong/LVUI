# 계층 드래그 이동 계획

`HierarchyDrag`는 선택한 항목과 원본의 불변 스냅샷을 보관하고 포인터 위치를
이동 후보로 변환한다. 드래그 이동 자체는 화면 상태이며 문서를 수정하지 않는다.
손을 놓았을 때 받은 요청만 앱의 교체 가능한 `HierarchyEditor::move()`에 전달한다.
편집기는 요청의 리비전을 다시 확인하므로 외부 변경 이후 오래된 이동이 커밋되지 않는다.

기본 이동 시작 임계값은 4단위이고 스크롤 방향을 알려주는 가장자리 크기는 16이다.
표시 중인 행의 위쪽·가운데·아래쪽은 각각 대상 앞, 대상의 자식, 대상 뒤를 의미한다.
마지막 행 아래의 빈 공간은 최상위 끝을 뜻한다. 이동 불가 항목이나 비활성 대상을
거절하고, 자신 또는 자손으로의 순환과 실질적으로 변하지 않는 이동은 후보로 내놓지
않는다. 가상 뷰포트의 소스 리비전이 달라지면 후보를 버린다. 스크롤 시간과 속도,
하이라이트, 입력 장치 캡처 및 실제 편집 요청은 이를 조합하는 호스트의 책임이다.
`finish()`는 후보를 한 번만 반환하며 `cancel()`은 후보를 폐기한다.

`LVUI.OwnedHierarchy.Drag`는 이동 임계값, 배치 구간, 원본 비변경, 자기 자손 거절,
비활성 대상, 빈 공간, 오래된 후보, 취소와 가장자리 스크롤 방향을 검사한다.
독립 `HierarchyList`는 이 계획을 포인터 캡처와 교체 가능한 편집기에 연결한다.
가장자리 스크롤은 포인터 이동 이벤트당 한 행씩 진행한다.
